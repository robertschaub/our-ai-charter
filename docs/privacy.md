# Privacy notice

Last updated: 22 September 2026

Our AI Charter is a public research and documentation project. Its website is a static GitHub Pages site. It has no user accounts, submission forms, payment functions, advertising, project-controlled audience analytics, or externally hosted fonts or media.

## 1. Controller and scope

The project is stewarded by **FactHarbor, a Swiss non-profit association (Verein) based in Dietlikon, Switzerland**. For project-controlled processing described here, FactHarbor is the controller.

- Contact: [info@factharbor.ch](mailto:info@factharbor.ch)

This notice covers the website at `robertschaub.github.io/our-ai-charter`, the public `robertschaub/our-ai-charter` repository and project interactions, and messages sent to the project contact address. Other websites and platforms reached through links apply their own privacy notices.

## 2. Data and purposes

| Situation | Data involved | Purpose |
| --- | --- | --- |
| Visit the website | IP address and ordinary request metadata processed by GitHub | Deliver and secure the site |
| Use site preferences or search | Display, navigation, and search state stored locally in your browser | Provide the interface and client-side search |
| Contribute through GitHub | GitHub identity, public contribution, timestamps, and related metadata | Public review, attribution, correction, and project history |
| Email us | Address, message, attachments, and correspondence metadata | Reply, handle requests, and maintain necessary follow-up records |

Public issues, pull requests, commits, and discussions are public by design. The project does not receive the browser-local preference and search state described above.

## 3. Providers and transfers

**GitHub** hosts the repository and website. GitHub states that it logs the IP address of every GitHub Pages visitor for security. It also processes GitHub account, contribution, and service data under its [General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). That statement says GitHub processes data in the United States and other countries where it or its subprocessors operate; GitHub does not publish a Pages-specific country list. For transfers from Switzerland to countries without an adequate level of protection, GitHub states that it uses the Swiss-U.S. Data Privacy Framework and/or standard contractual clauses.

**Infomaniak Network SA** provides the project email service. Its [service information](https://www.infomaniak.com/en/ksuite/service-mail) states that email data is hosted in Switzerland.

## 4. Retention

- **Browser-local settings:** remain until you clear site data or the browser removes them.
- **Public contributions and Git history:** remain as part of the public project record unless corrected or removed where appropriate. Copies may persist in forks, clones, or quotations.
- **Correspondence:** no fixed maximum period has been adopted. Retention depends on the time needed to answer and follow up and on any longer legal, dispute, or necessary project-record purpose.

## 5. Your rights

Depending on the applicable law and circumstances, you may request access, correction, deletion, restriction, objection, or data portability. Contact [info@factharbor.ch](mailto:info@factharbor.ch) for project-controlled data. GitHub handles requests concerning data it controls through the routes in its privacy statement. We may verify identity and authority before disclosing or changing data.

Public Git records cannot always be erased from distributed copies. We will nevertheless assess reasonable correction, redaction, or removal measures where appropriate.

You may complain to the [Swiss Federal Data Protection and Information Commissioner (FDPIC)](https://www.edoeb.admin.ch/en).
