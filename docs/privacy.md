# Privacy notice

Last updated: 22 September 2026 · Draft version: 0.4

## At a glance

Our AI Charter is a public research and documentation project. The website is a static GitHub Pages site. It has no user accounts, submission forms, payment functions, advertising, or project-controlled audience analytics.

When you visit, GitHub serves the site and records technical request data. The current theme also loads Google Fonts. If you contact us or contribute through GitHub, we process the information you choose to provide. Public issues, pull requests, commits, and discussions are public by design.

The project is stewarded by **FactHarbor, a Swiss non-profit association (Verein), c/o Robert Schaub, In Lederäcker 11, 8305 Dietlikon, Switzerland**.

- Privacy and general contact: [info@factharbor.ch](mailto:info@factharbor.ch)
- Serviceable postal address: **FactHarbor, c/o Robert Schaub, In Lederäcker 11, 8305 Dietlikon, Switzerland**

GitHub and Google determine some processing independently for their own services. Their notices apply to that processing.

## 2. Scope

This notice covers:

- the Our AI Charter website at `robertschaub.github.io/our-ai-charter`;
- the public `robertschaub/our-ai-charter` GitHub repository and project interactions;
- messages sent to the project contact address.

It does not govern websites reached through external links, LinkedIn, or other platforms that publish Charter-related material under their own notices.

## 3. Data and purposes

| Situation | Data involved | Purpose |
| --- | --- | --- |
| Visit the website | IP address and ordinary HTTP metadata processed by GitHub; font requests sent to Google, including ordinary request metadata | Deliver and secure the site; render its typography |
| Use site preferences or search | Theme preferences such as `__prefs` and `__palette` may be stored in `localStorage`; instant-navigation/session state may use `sessionStorage`; client-side search state may also be held locally | Provide the interface and client-side search |
| Follow an external link | The destination receives a normal request after you choose the link | Open the referenced source or platform |
| Open an issue, pull request, discussion, or commit | GitHub identity, public contribution, timestamps, and related metadata | Public review, attribution, correction, and project history |
| Email us | Address, message, attachments, and correspondence metadata | Reply, handle requests, and maintain necessary follow-up records |

We do not sell personal data, create advertising profiles, or use contribution data for model training.

## 4. Legal grounds and principles

We process data under the Swiss Federal Act on Data Protection (FADP) in accordance with lawfulness, good faith, transparency, purpose limitation, proportionality, accuracy, and security.

Where the EU/EEA GDPR applies, the principal grounds are:

- legitimate interests in publishing, securing, maintaining, and improving an open public-interest research project (Article 6(1)(f));
- taking steps requested by you or handling a project relationship where Article 6(1)(b) applies;
- compliance with legal obligations where Article 6(1)(c) applies.

Consent is used only where a specific optional activity actually requires it; this notice does not treat ordinary site use as blanket consent.

## 5. Providers, public records, and transfers

### GitHub

GitHub hosts both the repository and the Pages site. GitHub states that it logs visitor IP addresses for GitHub Pages for security. GitHub also controls account, contribution, and platform telemetry data under its [General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Public Git history can be copied and redistributed through forks and clones.

### Google Fonts

The current site theme automatically requests font CSS and files from `fonts.googleapis.com` and `fonts.gstatic.com`. Google receives the network information needed to answer those requests under its own privacy terms. The project intends to replace these remote requests with repository-hosted fonts; until that change is made, the Google requests remain part of the site's current operation.

### Other websites

External links are normally contacted only when you select them. No externally hosted media embed was found in the reviewed documentation tree. Future project pages or standalone slide files may nevertheless contain such media; if it is embedded, its host receives a request when the media loads. Authors should prefer repository-hosted assets for privacy, availability, and provenance.

These providers may process data outside Switzerland. The association must assess and document the relevant provider roles and any required Swiss or EU transfer safeguards; a provider's global availability does not by itself establish an adequate transfer basis.

## 6. Retention

- **Website request and provider logs:** retained according to GitHub's and Google's applicable service policies; the project cannot delete those independent provider logs directly.
- **Browser-local settings:** remain until you clear site data or the browser removes them.
- **Public contributions and Git history:** retained for the durable public record. They may remain in forks, clones, releases, archives, or quoted discussion even if the original platform item is later changed.
- **Privacy and support correspondence:** proposed maximum of two years after closure, unless a shorter period is sufficient or law, a dispute, or an overriding documentation need requires longer.

We ask contributors not to publish secrets, private correspondence, unnecessary personal data, or allegations about identifiable people. For sensitive material, use the private contact address instead of a public issue.

## 7. Your rights

Depending on the law and circumstances, you may request access, correction, deletion, restriction, objection, or data release/portability. Email [info@factharbor.ch](mailto:info@factharbor.ch) with enough information to identify the relevant record. We may verify identity and authority before disclosing or changing data.

Public Git records cannot always be fully erased from distributed copies. We will nevertheless assess reasonable correction, redaction, repository-history, or platform-removal measures where appropriate.

You may complain to the [Swiss Federal Data Protection and Information Commissioner (FDPIC)](https://www.edoeb.admin.ch/en) or, where the GDPR applies, the competent EU/EEA supervisory authority.

## 8. Security and children

We use a public repository, restricted maintainer permissions, review practices, and HTTPS provided by GitHub. No internet service can guarantee absolute security. Report suspected leaked secrets or private personal data privately to [info@factharbor.ch](mailto:info@factharbor.ch), not in a public issue.

The project is not designed to collect children's data. Do not submit personal data about a child in a public contribution.

## 9. Changes and approval

Material changes will be recorded in the repository and changelog. A dated version becomes effective only after the responsible association body approves it. The operational approval checklist is maintained in the association's private administrative records rather than on this public page.
